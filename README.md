# Thilip 3D Portfolio

Open `index.html` with VS Code Live Server or another local web server. The site uses Three.js from a CDN.

## Replace later
- Sample T. avatar with your photo
- `your@email.com` with your email
- Sample projects with your actual projects/screenshots/URLs
- Timeline with exact companies, roles and dates
- GitHub placeholder link

## WordPress conversion
The same design can be converted into a custom WordPress theme. ACF can manage projects, skills and experience entries.
